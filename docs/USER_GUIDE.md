# Open Registry User Guide Manual

This guide is for people who use the system for day to day office activities; Senior Records Officer, Assistant Records Officer, Records Officer,Data Entry clerks & Office Attendants.
# 1. What this system does / Functionalities
Keeps Electronic registers, table lists of files/records in one place.
Lets you search and view particular entries and registers.
Lets you add or change records only for authorized registers assigned.
Enables administrator tools; user accounts, data import/upload, exports, and status reporting.

# 2. User roles
The system provides mainly Administrator and User roles which are the Senior Admin and other office staff users.
# 2.1 Users
Users access the dashboard by Clicking on Access User Portal, to access the User Login screen
You can:
  Open the dashboard and see quick summaries by numbers.
  View any register (read only) via View Database in the vertical navigation bar.
  Edit only the registers your admin selected & authorized for your account usually up to three per user.
  Regular Users are not authorized and restricted from accessing the full admin dashboard, bulk import, or user creation unless given an admin access account as well.
# 2.2 Admin Access
You sign in on the Admin login screen by Clicking on Access Admin Portal.
Admins use a different account table from normal users.
You can:
  Use the Admin dashboard.
  Create and manage users and their module assignments.
  Import spreadsheet data in csv file formar.
  Use status manager & analytics to export data for stored media.
# 2.3 Get Help 
From the home page footer & User login screen, Click Get Help.
You can read & review the User guide manual and use Ask a question to send your email and a message for feedback.
# 3. Signing in step by step guide
# Regular user
1. Open Open Registry home page.
2. Choose Access User Portal to login or directly click User Login if bookmarked.
3. Enter Username and Password given by your administrator.
4. After login you should land on User dashboard.
# Administrator
1. Open the home page.
2. Choose Admin login.
3. Enter Admin username and Password.
4. You should land on Admin dashboard.
# Signing out
Use Sign out / Logout on the dashboard or sidebar.
Always sign out for shared computers.
# 4. User dashboard for everyday tasks
# 4.1 See your overview
The dashboard shows totals such as entries per today and your contributions.
# 4.2 View any register (read only)
1. Click View Database in the sidebar.
2. In the modal, choose the register / table you want to view e.g. Master Register, Pensioners Register.
3. Click View Table.
4. You will open the database viewer with that table selected. You can search, sort, and refresh.
5. Export CSV in that viewer is for administrators only; regular users browse only.
# 4.3 Edit a register for only Authorized Registers
1. Click Edit Register.
2. In the modal, choose a register from the list only authorized registers appear.
3. Enter how many rows you want to work on.
4. Click Start editing. The system opens the spreadsheet-style entry screen for that register.
If you need access to another register, ask your senior administrator to update your assigned modules.
# 5. Spreadsheet style editing
Move between cells with Tab / Enter where supported.
Save behaviour depends on the screen: many modules save a row when required fields are completed.
Yellow highlight or messages confirm a successful save.
Incase you see a warning about missing required fields, complete those cells for the row to be saved.
Refer to the official data standards how file numbers, dates, and statuses should be written.
# 6. Behaviour to remember
View any register, for any logged in user .
Edit only registers assigned and authorized by the senior admin to your user account.
If a link sends you to the wrong dashboard, sign out and sign in again with the correct portal (User vs Admin).

# 8. Getting help

1. Confirm you used the correct login page.
2. Confirm your account has the right assigned registers for editing.
3. For technical errors (blank page, database error), contact your IT administrator immediately with the page you were on and what you clicked last.
